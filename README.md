# TimeWard — versions publiées

Ce dépôt ne contient que les versions publiées de **TimeWard**, le serveur d'heure (NTP) pour Windows de Sarto Groupe. Le code source n'y est pas.

Chaque version est accompagnée d'un fichier `version.json` signé par Sarto Groupe. Avant de proposer une mise à jour, TimeWard vérifie cette signature, l'empreinte du fichier et le numéro de version, et refuse tout le reste — même venu de ce dépôt. Rien ne s'installe sans l'accord de la personne devant le PC.

Installer à la main : télécharger `TimeWard.exe` depuis la [dernière version](https://github.com/SartoL71/timeward-releases/releases/latest), puis double-cliquer dessus.
